# Northstar Opportunities

Minimum credible web presence for the Northstar Opportunities validation phase.

## Purpose
Northstar identifies and qualifies early U.S. government contracting signals for small-business contractors using authoritative public evidence.

## Deployment
Static site: `index.html`. No build dependencies, database, analytics, cookies, API keys, environment variables, or third-party JavaScript are required.

## Security policy
This repository is intentionally isolated and contains only material intended for public release. Never commit passwords, tokens, API keys, `.env` files, customer confidential information, financial data, private opportunity briefs, or personal documents.

## Integrity policy
Do not publish client logos, testimonials, certifications, award claims, government affiliations, or success metrics unless independently verifiable and authorized for publication.
